# BBSBot
Bleach Brave Souls Bot

## Features:
- Auto play boring quests
  - Epic Raids (need to auto clear solo)
  - Event Quests
- Simple GUI

## How to Build:
1. Clone repository
`git clone https://github.com/antonioThomaz1903/bbsbot.git`
2. Create virtualenv
`python -m venv .venv`
3. Activate the virtualenv `Linux`:`./.venv/bin/activate` `Windows`: `/.venv/bin/activate.bat`
4. Install requirements `pip install requirements.txt`
5. Run `python main.py`


## Epic Raids:
- Start on the create room page
- Disable mvp warning

## Event Quests:
- Start on the start quest page
